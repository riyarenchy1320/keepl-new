KEEPL — local website concept

Open index.html directly, or serve this directory:
  python3 -m http.server 4173 --bind 127.0.0.1
Then visit http://127.0.0.1:4173

Files: index.html, styles.css, app.js, assets/
No npm installation or build step required. Fonts and imagery are local.

Seven homepage sections: hero, whole-section horizontal credentials, animated parent partnership,
full-width sticky services, filterable parent projects, looping service marquee, enquiry CTA.
Includes reduced-motion support, keyboard-accessible dialogs and responsive layout.

Preview limitations:
- No form submission, backend, CMS, analytics or file uploads are connected.
- KEEPL uses a temporary text wordmark. Parent logos sourced from their official sites.
- Ownership displayed as 60% Kilburn / 40% East End, as instructed by the client in the design revision.
- Credentials/projects are attributed to parent experience.
- No invented contact details, vacancies, certificates or project dates.
- Resource/QHSE/download/career navigation opens informational preview dialogs.
